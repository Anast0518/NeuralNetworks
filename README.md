В файлах ipynb представлена реализация следующих нейронных сетей:
1. gradient_nn.ipynb - представляет собой реализацию метода градиентного спуска в том числе с оптимизаторами, такими как Adam, AdaGrad и метод Нестерова.
2. graph_nn.ipynb - реализация нейронной сети, которая на основе исходной функции строит ее график.

3. predict_y - папка, сожержащая файл с кодом predict_y.ipynb, папку runs для tensorboard, а также папку с обученными моделями models. Задача нейронной сети предсказывать столбец Y по остальным. Цель - вызвать переобучение, возрастание графика test loss.
